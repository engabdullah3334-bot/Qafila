## 🔒 فلسفة المشروع والعامل الأمني

### لماذا لا يقوم المشروع بالنشر التلقائي بالكامل؟
فيسبوك يطبق سياسات صارمة للغاية ويمنع أي أداة خارجية من:
1. سحب قائمة جروباتك تلقائياً دون تصريح رسمي.
2. نشر المنشورات في الجروبات نيابة عنك عبر المتصفحات الآلية (Headless Browsers أو Selenium).

> ⚠️ **تنبيه هام:** أي أداة تدّعي "النشر التلقائي السحري" تعتمد على محاكاة متصفح غير مصرح به، وهو ما تكتشفه خوارزميات فيسبوك بسهولة فائقة، مما يؤدي إلى تقييد الحساب أو حظره نهائياً في وقت قصير.

### حل «قافلة»:
المشروع يحل المشكلة من جذورها عبر **"أتمتة التنظيم وتبسيط النشر البشري"**:
- الاحتفاظ بجروباتك وروابطها في مكان واحد.
- فتح كل جروب برابط مباشر بلمسة واحدة.
- نسخ النص تلقائياً للحافظة بنقرة واحدة (One-Tap Copy).
- توجيهك خطوة بخطوة بالترتيب.
- **النتيجة:** توفير 90% من الوقت والمجهود، مع بقاء النشر بشرياً 100% وآمناً تماماً أمام فيسبوك.

## 🤖 1. بوت تيليجرام الذكي (`bot.py`)

تم تصميم البوت ليكون المساعد الشخصي الأقوى للنشر اليومي، حيث يستغل كافة إمكانيات تيليجرام التفاعلية.

### المميزات الرئيسية للبوت:
1. **النسخ التلقائي بنقرة واحدة (One-Tap Copy):**
   - يظهر نص المنشور داخل قالب كود `<pre>` مهيأ، بحيث يكفي لمس النص في تطبيق تيليجرام (هاتف أو كمبيوتر) ليتم نسخه فوراً إلى الحافظة.
2. **الانتقال المباشر للجروب:**
   - زر شفاف `🌐 فتح الجروب في فيسبوك` يفتح الجروب المطلوب مباشرة في تطبيق أو متصفح فيسبوك.
3. **تسيير القافلة التفاعلية:**
   - الانتقال بين الجروبات بالترتيب مع عداد خطوات `[المحطة 2 من 8]`.
   - زر `✅ تم النشر — التالي ➡️`، وزر `⏭️ تخطي هذا الجروب`، وزر `🛑 إنهاء القافلة`.
   - تقرير ملخص نهائي يوضح عدد المجموعات المنشورة والمتخطاة.
4. **تحديد مخصص للمجموعات:**
   - إمكانية اختيار "تحديد الكل" أو اختيار مجموعات معينة عبر أزرار تفاعلية (Checkboxes) `[✅ اسم الجروب]`.
5. **دعم الميديا والصور:**
   - يمكنك إرسال نص عادي، أو صورة مع نص، وسيعيد البوت إرسال الصورة في كل محطة لتنزيلها أو مشاركتها.

---

### نظام حفظ واسترجاع النصوص
خاصية تتيح لك عدم كتابة نفس المنشور أكثر من مرة:
- **الحفظ التلقائي:** أي نص ترسله للبوت يتم حفظه تلقائياً في قائمة نصوصك للرجوع إليه لاحقاً.
- **إعادة الاستخدام بلمسة واحدة:** عند بدء قافلة جديدة، تظهر أحدث نصوصك المحفوظة كأزرار سريعة لاختيارها مباشرة.
- **قسم «📝 النصوص المحفوظة»:**
  - استعراض جميع القوالب المحفوظة وتواريخها.
  - إطلاق القافلة بالنص فوراً.
  - إضافة نصوص جديدة أو حذف النصوص القديمة.

---

### نظام التذكير الدوري (كل 4 ساعات)
ميزة ذكية تعمل بخيط معالجة خلفي مستقل (`threading.Thread`):
- يرسل البوت تنبيهاً تلقائياً كل **4 ساعات** لتذكيرك بنشر قافلة جديدة للحفاظ على نشاط الجروبات.
- زر مخصص بالقائمة الرئيسية باسم **`⏰ إعدادات التذكير (4 ساعات)`** (وأمر `/remind`):
  - معرفة موعد التذكير القادم بالدقيقة والساعة.
  - تفعيل أو إيقاف التذكيرات بضغطة زر.
  - زر **`🧪 تجربة التنبيه الآن`** لاختبار شكل الرسالة.

---

### أوامر البوت:
| الأمر | الوظيفة |
|---|---|
| `/start` | فتح القائمة الرئيسية وتسجيل التذكير الدوري |
| `/newpost` | بدء تجهيز منشور وتسيير قافلة جديدة |
| `/posts` | استعراض وإدارة النصوص المحفوظة |
| `/groups` | عرض المجموعات المحفوظة وإدارتها |
| `/addgroup` | إضافة مجموعة جديدة (الاسم + الرابط) |
| `/remind` | ضبط إعدادات التذكير الدوري (كل 4 ساعات) |
| `/export` | تصدير قائمة الجروبات كملف `groups.json` |
| `/cancel` | إلغاء أي خطوة حالية والعودة للقائمة الرئيسية |
| `/help` | عرض دليل الاستخدام وإرشادات الأمان |

### طريقة إعداد وتشغيل البوت:

#### 1. المتطلبات:
- تثبيت Python 3.8 أو أحدث.
- تثبيت مكتبة تيليجرام:
```bash
pip install pyTelegramBotAPI requests
```

#### 2. توكن البوت (Bot Token):
- افتح [@BotFather](https://t.me/botfather) في تيليجرام وأنشئ بوتاً جديداً للحصول على التوكن.
- انسخ `.env.example` إلى `.env`، ثم ضع التوكن في قيمة `TELEGRAM_BOT_TOKEN`. يقرأ `bot.py` الملف `.env` تلقائياً، وملف `.env` مستثنى من Git:
```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```
- بدلاً من ذلك، يمكنك ضبط متغير البيئة قبل التشغيل:
```powershell
$env:TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN_HERE"
```

#### 3. التشغيل:
باستخدام البيئة الافتراضية للمشروع:
```powershell
# على نظام ويندوز
.venv\Scripts\python.exe bot.py

# أو باستخدام بايثون الافتراضي
python bot.py
```

## 🌐 2. أداة المتصفح المستقلة (`qafila-group-poster.html`)

واجهة ويب عصرية جاهزة لا تحتاج إلى تثبيت بايثون أو أي خوادم:
- **التشغيل:** انقر نقراً مزدوجاً على الملف `qafila-group-poster.html` ليفتح في متصفحك (Chrome، Edge، Firefox).
- **الخصوصية:** جميع بيانات الجروبات والنصوص تحفظ محلياً فقط داخل متصفحك (`localStorage`).
- **المميزات:**
  - إدارة الجروبات وإمكانية البحث والتحديد السريع.
  - دعم رفع الصور والفيديوهات وتنزيلها بضغطة زر لرفعها على فيسبوك.
  - تصدير واستيراد قائمة الجروبات عبر ملفات JSON.
  - نسخ النص تلقائياً وفتح الجروبات في تبويبات جديدة.

## 💻 3. أداة سطر الأوامر (`qafila_cli.py`)

لمن يفضلون العمل الخفيف وسريع الاستجابة من خلال سطر الأوامر:
- **التشغيل:**
```bash
python qafila_cli.py
```
- **طريقة العمل:**
  1. إضافة الجروبات تفاعلياً عند التشغيل لأول مرة (تحفظ في `groups.json`).
  2. تحديد أرقام الجروبات المرادة (مثال: `1,3,5` أو `all`).
  3. إدخال نص المنشور وإنهائه بكلمة `END`.
  4. نسخ النص للحافظة تلقائياً وفتح كل جروب في المتصفح بالتتابع.
  5. الضغط على `Enter` للمتابعة، أو `s` للتخطي، أو `q` للإيقاف.

## 🔄 التوافق ومزامنة البيانات

تعتمد جميع أدوات المشروع (`bot.py` و `qafila_cli.py` و `qafila-group-poster.html`) على نفس بنية ملف البيانات:
```json
[
  {
    "name": "اسم الجروب",
    "url": "https://www.facebook.com/groups/example"
  }
]
```
- **المزامنة مع البوت:** عند وضع ملف `groups.json` في مجلد المشروع، سيقرأه البوت تلقائياً ويعتمده لجروباتك.
- **الاستيراد الفوري في تيليجرام:** يمكنك سحب وإفلات أي ملف `.json` في شات البوت وسيقوم باستيراد المجموعات ودمجها تلقائياً بدون تكرار!
- **النسخ الاحتياطي:** استخدم زر `📤 تصدير` في البوت لتنزيل نسخة احتياطية من جروباتك في أي لحظة.

## 🛡️ نصائح ذهبية لحماية حساب فيسبوك

1. **التمهل بين المنشورات:** خذ وقتاً طبيعياً بين نشر الجروب والآخر (30 إلى 60 ثانية). هذا السلوك البشري الطبيعي يبعد الشبهات عن حسابك.
2. **تجنب النشر في عشرات الجروبات دفعة واحدة:** قسّم عمليات النشر على دفعات على مدار اليوم (وهذا ما يساعدك عليه نظام التذكير كل 4 ساعات!).
3. **احترام قوانين الجروبات:** تأكد من أن محتوى منشورك يطابق شروط الجروب لتجنب قيام مسؤولي الجروبات بالإبلاغ عن حسابك.
